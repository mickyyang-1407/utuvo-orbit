# Security

Orbit is a local native utility. It does not have a server, account system or telemetry endpoint.

Please do not post secrets or a detailed exploit in a public issue. For a suspected security defect, use GitHub's private vulnerability-reporting option if it is enabled. If it is unavailable, open a minimal issue asking for a private contact route without disclosing exploit details or sensitive data.

Normal UI bugs and unsupported device readings belong in ordinary issues, with identifying information removed. There is no security response-time guarantee or bug-bounty program.

Only the newest published release is maintained. Verify downloads and read the current signing/notarization statement before installing.
