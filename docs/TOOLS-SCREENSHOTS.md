# Orbit 0.9 工作台 / Workbench

尚未發布的本機候選版。以下為 App 的真實介面搭配明確標示的示範資料；一般預覽停用檔案操作、原生取色及通知，使用假的剪貼簿、硬體、App 啟動與快捷鍵。原生截圖擷取仍未驗收。

Unreleased local candidate. App renders use labeled demo data, fake clipboard/hardware/App launches/hotkeys, and disabled file actions, native sampling and notifications. Native screenshot capture is still unaccepted. These images verify layout, not live hardware behavior.
