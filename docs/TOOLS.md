# 隨手工具 / Quick Tools

Available in the unreleased 0.9 local candidate. / 適用於尚未發布的 0.9 本機候選版。介面見[畫面圖集](TOOLS-SCREENSHOTS.md)。

## 開啟

按主面板底部「工具」，或在選單列 Orbit 圖示按右鍵。啟用檔案架後，也可從檔案架右鍵開啟檔案工具，直接帶入架上的檔案。工具跟隨 Orbit 的語言與主題。

## 情境模式

從側欄「情境模式」建立配方，選擇已儲存的音訊情境、0–120 分鐘倒數、30／60／120 分鐘喚醒，以及最多 8 個由選檔器挑選的 App，再按儲存。下次按「啟動」才執行；啟動 Orbit 不會自動套用。最多儲存 24 個配方，可編輯或刪除。

正在計時時，不會用另一個情境覆蓋計時。失效的音訊情境或 App 書籤會先阻止啟動；執行中失敗則顯示已完成步驟可能仍生效。情境的喚醒與主面板、計時器各自獨立，可按「解除情境的喚醒」結束。若選到的音訊情境本身也包含喚醒，該設定仍依音訊情境原有行為執行。

## 快捷動作

工具窗按 ⌘K，或由選單列右鍵選「快捷動作」。輸入工具或已儲存情境的名稱，用 ↑／↓ 選取、Return 執行、Escape 關閉；圖釘可把動作排到前面。關閉後再開會重新聚焦搜尋欄。

「快捷動作」頁可選擇開啟全域 ⌃⌥Space；預設關閉，註冊失敗會顯示提示，仍可由選單開啟。這個快捷鍵與晾衣繩的 ⌃⌥T 各自獨立。

## 聰明提醒

在「聰明提醒」明確開啟才請求 macOS 通知許可。可選 Mac 低電量、Mac 充電達標、周邊低電量及網路由連線變離線，低電量門檻為 5–50%，充電目標為 80–100%。沿用 SystemMonitor 的讀值，不新增硬體輪詢。

同一狀態只提醒一次；電量恢復超過門檻 5 個百分點、接上電源／充電，或網路恢復後才重新待命。未知值不會當成 0 或 100%；初次讀到離線不通知。通知是否出現仍由 macOS 許可與專注模式控制；當次事件保留最多 20 筆，結束 App 後不保留。

## 剪貼簿

先開啟「記錄新的剪貼簿內容」。只從下一次複製開始記錄；開關關閉或商店存取鎖定時不收集新項目。可搜尋、置頂、複製、移除，文字也可直接送到文字工具。清除清單不會改動目前系統剪貼簿。

最多 50 筆、16 MB；單筆文字最多 200 KB，圖片最多 4 MB／1600 萬像素／每邊 8000px。超出總量時先移除最舊的未置頂項目。相同內容會合併。系統剪貼簿標為 Concealed／Transient／AutoGenerated 或特定密碼工具類型的內容會略過；無法判斷未標記文字是否敏感，可隨時暫停或移除。

內容只存在本機 Application Support 的 `UTUVO Orbit/Clipboard/history.json`（MAS 在自己的沙盒），檔案權限 600、資料夾 700，沒有同步或上傳。損壞時停止寫入，需明確「備份並重設抽屜」；備份仍留在同一個本機目錄。

## 文字工具

支援逐行清理空白、移除空白行／重複行、大小寫、JSON 排版、URL 與 UTF-8 Base64 編解碼。貼上純文字可移除格式。按「轉換」後可複製、用作下一次輸入，或直接產生 QR Code。輸入與結果在本次工作階段切頁後保留，結束 App 後清除；編輯輸入或切換操作會清掉舊結果，避免複製過期內容。單次最多 1 MB。

## PDF

合併 PDF 可加入最多 50 份文件，按 ↑／↓ 調整順序。擷取、逐頁拆分或旋轉 90° 使用一份 PDF，頁碼可填 `1-3,5`，留空表示全部；重複頁碼只保留第一次出現，保留指定順序。「圖片轉 PDF」依選擇順序建立頁面。

選擇輸出資料夾後，每次都建立新的 `Orbit Export …` 資料夾，不覆寫原檔。總輸入上限為 200 MB／500 頁，加密或無法讀取的 PDF 會停止。旋轉操作輸出所選頁面；PDF 工具是文件整理功能，不保證保留原文件的互動表單、數位簽章或整份文件的書籤結構。

## 取色器與 QR Code

取色器可輸入六位 HEX，或使用 macOS 系統取色器選色；複製 HEX／sRGB 整數 RGB，收藏最多 30 個顏色。按色塊重新選取，按色碼直接複製。損壞的配色資料保留至明確備份重設。

QR Code 支援 1–1800 UTF-8 bytes，輸出含四模組白邊的清晰 PNG；文字工具結果可直接帶入。也可從圖片辨識，或從「截圖」頁把編修後像素送來辨識。只顯示／複製文字，不會自動開啟連結。生成與辨識均不連網。

## 音訊情境

1. 選擇目前輸出與輸入。音量可在主面板調整。
2. 輸入情境名稱，選擇是否記住音量，以及是否附加 30／60／120 分鐘保持喚醒。
3. 按「儲存目前的音訊設定」。下次按該情境的「套用」。

情境存在本機，啟動 App 或儲存情境都不會自動套用。裝置依 UID 辨識；沒有連線或無法唯一辨識時，套用前會顯示錯誤。如果裝置在切換途中斷線，部分設定可能已改變，請查看目前裝置。硬體音量裝置不會保存軟體音量；App 不會錄音。

每個情境的「⋯」可重新命名或向上／向下移。已儲存資料損壞時，不會用新儲存覆寫；按「備份並重設情境」才建立本機偏好備份並重設。

## 倒數與番茄鐘

倒數有 5／15／25／50 分鐘選項，可暫停、繼續或重設。番茄鐘為 25 分鐘專注、5 分鐘休息；每段結束後，按按鈕才開始下一段，並顯示本輪完成的專注次數。重設會清除次數。

自訂倒數可設 1–120 分鐘。分鐘數、模式、喚醒與通知選項會保存；重新開啟 App 不會自動開始計時。切換番茄鐘不會覆蓋原本的自訂倒數分鐘數。

睡眠期間經過的時間會計入倒數。關閉工具窗不會停止計時，結束 Orbit 則會停止。可選「計時時保持喚醒」；暫停、重設或完成只解除計時器自己的喚醒，不會取消主面板的手動喚醒。它無法阻止闔蓋或手動睡眠。「完成時通知」會在勾選時請求 macOS 通知許可；未允許仍可正常計時。

## 檔案處理

選擇檔案，或按「從檔案架加入」，再選操作與輸出資料夾：

也可把檔案直接拖進待處理區；重複的路徑只保留一份，個別項目的「×」只移除參照，不刪檔。

| 操作 | 結果 |
| --- | --- |
| 打包 ZIP | 可包含檔案與資料夾；同名項目會自動加編號 |
| 縮至 1600px · PNG | 長邊至多 1600px，不放大小圖 |
| 轉成 PNG／JPEG | 保留原圖尺寸並依方向資訊旋正；JPEG 透明區域填白 |
| 複製檔案路徑 | 將所選路徑逐行放入剪貼簿 |

每次處理都建立新的 `Orbit Export …` 資料夾，原檔保持不變。圖片操作只輸出第一張影格，不保留動畫／多頁內容；單張圖片上限為 8,000 萬像素且每邊不超過 32768px。ZIP 的輸出位置須在來源資料夾之外，避免把輸出再次包含進來源。處理失敗會清除該次未完成的輸出資料夾。

## 截圖與編修

使用 macOS 的 ⌘⇧4／⌘⇧5 儲存截圖，再在「截圖」頁按「匯入圖片」。這條匯入、編修、匯出流程已在沙盒內實測。原生「擷取視窗／擷取螢幕」採系統內容選擇器與單張圖片 API，但目前這台測試 Mac 未出現選擇器，尚未通過實機驗收；如持續等待，可按「取消」並改用匯入。

在圖片上拖曳套用裁切、箭頭、框線或遮蓋，可按「復原」或「還原原圖」。每張圖的編修紀錄會保存在本機，切換最近截圖或重新開啟後仍可繼續；每張最多 32 次編修。紀錄損壞時保留原圖與原紀錄，需按「備份並還原原圖」才另存備份並重設。

「複製圖片」、「辨識文字」與「輸出 PNG」都使用編修後的像素，遮蓋是實際的不透明黑色像素。原圖仍保留在本機；分享時請使用編修後的輸出。「檔案工具」可接著做 ZIP／格式轉換；開啟晾衣繩模組後可「掛上晾衣繩」，只傳送副本。最近清單顯示最新 24 張，其餘可由資料夾按鈕開啟素材庫查看。

## English

The sidebar workbench now includes **Modes, Actions, Reminders, Clipboard, Text, PDF, Colors and QR Code**, alongside audio, timer, file and screenshot tools.

- **Modes:** save up to 24 recipes combining an audio scene, optional countdown, a separate keep-awake assertion and up to eight user-selected Apps. Start explicitly. Active timers and missing dependencies stop preflight. Partial failures report that earlier steps may remain active. App bookmarks may need reselecting after a move/update.
- **Actions:** press ⌘K inside the workbench or use the status menu. Search, use arrow keys and Return, close with Escape, and pin favorites. Optional global ⌃⌥Space is off by default and reports conflicts.
- **Reminders:** opt in to notifications for low Mac/accessory battery, a Mac charge target and a connected-to-offline transition. Uses the existing monitor. Battery alerts rearm after recovery with five percentage points of hysteresis; unknown data and initial offline state do not invent events. The session list holds 20 entries. macOS notification and Focus settings control actual delivery.
- **Clipboard:** off by default, records only future changes. Local searchable/pinnable text/image history, 50 items and 16 MB, oldest unpinned entries evicted first. Text limit 200 KB; images 4 MB/16 MP/8000px per side. Known concealed/transient/password-type entries are skipped, which cannot identify unmarked sensitive text. Pause or remove items whenever needed. History is a private local Application Support file, never uploaded; clearing history does not replace the current clipboard. Damaged bytes need explicit backup/reset, and that local backup is retained.
- **Text:** line cleanup, deduplication, case, JSON, URL and UTF-8 Base64. Paste plain text, transform, copy, chain as input or create a QR. Input/results survive page changes in the current session. Edits invalidate old output. Maximum 1 MB.
- **PDF:** merge/reorder, extract, split, rotate selected pages 90° or convert images. Use one PDF for non-merge actions and page selections such as `1-3,5`. Outputs go to unique new folders; originals are preserved. Limits: 50 inputs, 500 pages, 200 MB; encrypted/unreadable documents are rejected. Document-level forms, signatures and bookmark structure are not guaranteed to survive page assembly.
- **Colors:** native macOS color sampling, six-digit HEX, sRGB RGB and a saved 30-color palette.
- **QR:** local generation up to 1800 UTF-8 bytes, a four-module quiet zone, PNG export, image recognition and edited-screenshot handoff. Detected links are displayed as text and never opened automatically.


Open **Tools** in Orbit's panel or **Quick Tools** from its status-item menu. **Quick File Tools** in the shelf menu carries the shelf's current files into the window. Language and appearance follow Orbit.

**Audio scenes:** choose input/output, adjust volume in the main panel, enter a name, and save. Volume and 30/60/120-minute keep-awake are optional. Apply a scene explicitly; launching or saving never applies it. Saved devices are matched by stable UID. Missing or ambiguous devices stop the operation before a scene write. A disconnect during switching can leave some settings changed; inspect the current devices. Hardware-only outputs omit software volume. Orbit does not record audio.

**Timer:** choose a 5/15/25/50-minute countdown, or 25-minute focus / 5-minute rest Pomodoro. Pause/resume is supported. Each Pomodoro stage needs an explicit start; completed focus sessions reset with Reset. Sleep time counts. Closing the window leaves the timer running; quitting Orbit stops it. Optional keep-awake belongs to the timer alone, so pausing or finishing leaves manual keep-awake intact. It does not override lid closure or explicit sleep. Enabling completion notifications requests macOS permission; the timer also works without it.

**Files:** choose files/folders or add from the shelf, choose ZIP/PNG/JPEG/1600px PNG, then choose an export folder. Each job creates a new `Orbit Export …` folder and preserves originals. ZIP accepts folders and numbers duplicate names; choose a destination outside source folders. Image exports honor orientation, do not enlarge small images, flatten JPEG transparency onto white and export only the first frame/page. Images must be at most 80 megapixels and 32768px per side. Failed jobs remove only their own incomplete export. **Copy File Paths** copies one path per line.

Scenes also support rename/reorder and explicit backup/reset for damaged storage. The timer supports a custom 1–120-minute duration and saves options without restarting a countdown on launch. Pomodoro keeps the separate countdown duration. File drops merge and deduplicate paths; removing a reference preserves the file.

**Screenshots:** take a macOS screenshot with ⌘⇧4/⌘⇧5, then import it. The native ScreenCaptureKit window/display picker is not accepted on the test Mac; cancel if it does not appear and use import instead. Drag to crop, add arrows/boxes or apply opaque black redaction. Undo/reset and per-image edit history persist locally, with a 32-edit limit and backup/reset for damaged drafts. Copy Image, Copy Text and PNG export use the edited pixels. Originals remain local; share the flattened edited output. Send a copy to File Tools or an enabled Clothesline. The recent picker lists 24 items; the folder button opens the full library.
