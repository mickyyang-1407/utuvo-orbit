# 使用說明

點選選單列 Orbit 開啟面板，點外面或按 Escape 關閉。左下釘選可讓面板留在畫面上；釘選不會跨啟動保存。右下電源按鈕結束 App。

下面描述的是**目前本機候選版 1.0.0 (19)**。原始碼建置及重點模型檢查已通過，完整 App 的實際畫面驗收仍在進行中；**不是**已發布的下載檔；已發布的狀態見[版本與下載](#版本與下載)。

## 從哪裡開始：App 內的離線說明

Orbit 內建離線說明，沒有網路也能讀，離線時內容一樣完整。

- **⌘?** — Orbit 在前景時開啟說明。這是 App 局部快捷鍵，Orbit 不註冊任何全域快捷鍵。
- 選單列圖示右鍵選單裡的**使用說明**。
- 隨手工作台側邊欄底部的**使用說明**。
- 設定的最後一個分頁**說明**。

四個入口開的是同一份內容，會跟著 App 的目前語言。設定分頁直接內嵌說明，其餘三個在獨立視窗開啟，並附搜尋欄。

## 入口

- **面板** — 點選單列圖示。
- **設定** — 面板上的齒輪，或右鍵選單。
- **隨手工作台（18 個工具）** — 面板的「工具」、右鍵選單的「隨手工具」，或把檔案拖到檔案架。
- **快捷動作** — 工作台上的搜尋欄，或右鍵選單的「快捷動作」。
- **截圖** — 右鍵選單的「截圖與編修」，或工作台的截圖頁。
- **說明** — ⌘?，或右鍵選單的「使用說明」。

### 選單列圖示的右鍵選單

在圖示上按右鍵會開啟：開啟 UTUVO Orbit、設定與模組…、隨手工具…、快捷動作…、截圖與編修…、使用說明、檢查更新…（App Store 版為「在 App Store 更新」）、結束 UTUVO Orbit。若檔案架或截圖晾衣繩已開啟，另外會出現「檔案架：查看檔案」與「晾衣繩：顯示／隱藏 ⌃⌥T」。

選單上的 ⌘, / T / K 是選單自己的快捷鍵，只有在那個選單開著時有效，並非系統全域快捷鍵。Orbit 唯一在 App 層面處理的快捷鍵是 ⌘?。

## 同一個面板就夠了

上方的「總覽／網路／系統」只切換要看的資訊；下方顯示偏好一直都在，不必跳設定頁。

- **總覽**：音訊輸出、音量、靜音、保持喚醒、系統與網路概要。已確認的異常會顯示文字提示。
- **網路**：目前介面、本機 IPv4 與複製、即時上下載流量及趨勢。
- **系統**：CPU、記憶體、筆電電池、周邊電量。最多四個周邊，電量低的優先，未知排最後。

顯示偏好除了在面板，也在**設定視窗**（一般 → 外觀與語言）。設定視窗另外有登入啟動、選用模組與更新偏好。

## 隨手工作台：18 頁

側邊欄列出每一頁，全部都在你的 Mac 上執行。

| 頁面 | 用途 |
| --- | --- |
| 情境模式 | 把一組顯示偏好存成情境，之後一鍵切換 |
| 快捷動作 | 搜尋所有工具、情境模式、音訊情境、文字片段與快捷連結，直接執行 |
| 音訊情境 | 把輸出、輸入與音量存成情境，一鍵套用 |
| 計時器 | 倒數或 25／5 番茄鐘，可選保持喚醒與完成通知 |
| 世界時鐘 | 並排查看多個城市，可直接換算 |
| 聰明提醒 | 電量偏低、充電達標、周邊沒電或網路離線時提醒（由你開啟） |
| 剪貼簿 | 由你開啟的剪貼簿歷史 |
| 快速筆記 | 邊寫邊自動儲存，可匯出 Markdown，刪除後可從「最近刪除」復原 |
| 文字片段 | 帶關鍵字的可重用文字，動作搜尋找得到 |
| 快捷連結 | 你自己整理的連結與網址範本 |
| 檔案檢查 | 檢查檔案雜湊並讀回內容，確認副本或備份完好 |
| 文字工具 | 清理空白、格式化 JSON、編碼網址、比較字串 |
| 計算與換算 | 計算與單位換算 |
| 檔案處理 | 查看檔案、複製路徑、壓縮與解壓縮；原始檔不會被覆寫 |
| PDF | 合併、拆分、取頁、旋轉、把圖片集成一份文件 |
| 截圖 | 用 macOS 選取器擷取，再裁切、加註、遮蔽與 OCR |
| 取色器 | 從螢幕取色，複製成 HEX 或 RGB，收藏配色 |
| QR Code | 文字變 QR Code，也能從圖片或編修後的截圖辨識 |

工具之間可以接力：截圖 OCR 後可送到文字工具，剪貼簿內容可直接送去做 QR Code，片段可送進筆記，檔案路徑檢查完可複製到筆記。

## 鍵盤

| 鍵 | 作用 |
| --- | --- |
| ⌘? | 開啟離線說明（App 局部，不是全域快捷鍵） |
| ⌘Z / ⇧⌘Z | 復原、重做，在任何輸入框都一樣 |
| ⌘X ⌘C ⌘V ⌘A | 剪下、複製、貼上、全選 |
| ⌘K | 在隨手工作台搜尋所有動作 |
| ⌘S | 儲存目前編輯的筆記或片段 |
| Esc | 關閉面板，釘住與否都一樣 |
| ⌘Q | 結束 UTUVO Orbit |
| ⌃⌥T | 顯示或隱藏截圖晾衣繩（只在該模組開啟時） |

Orbit 不取代任何系統快捷鍵。你自己的 ⌘⇧3／⌘⇧4／⌘⇧5 截圖鍵照常可用，晾衣繩也只在你開啟它之後才註冊 ⌃⌥T。

## 你的資料在哪裡，怎麼拿回來

| 資料 | 位置 |
| --- | --- |
| 顯示偏好、主題、語言、釘選 | `com.utuvo.orbit` 偏好設定網域 |
| 筆記 | `~/Library/Application Support/UTUVO Orbit/Notes/notes.json` |
| 文字片段 | `~/Library/Application Support/UTUVO Orbit/Snippets/snippets.json` |
| 快捷連結 | `~/Library/Application Support/UTUVO Orbit/Quicklinks/quicklinks.json` |
| 剪貼簿歷史 | `~/Library/Application Support/UTUVO Orbit/Clipboard/`（只在剪貼簿工具開啟時） |
| 晾衣繩副本 | `~/Library/Application Support/UTUVO Orbit/Clothesline/` |
| 計算機紀錄、世界時鐘城市 | `com.utuvo.orbit` 偏好設定網域 |

**草稿。** 筆記與片段邊寫邊存。若結束 App 時還有沒存好的內容，Orbit 會先問你要繼續編輯還是不要儲存就離開，不會默默丟掉。

**資料損壞。** 若檔案無法讀取，Orbit 會保留原始損壞檔、明確告知，並提供「備份並重設」，不會直接覆寫。

**備份與復原。** 筆記、文字片段與快捷連結的頁面裡都有「備份與匯入」：可匯出成 JSON 備份到你選的資料夾，之後再匯入。匯入前會先預覽，而且**只會新增**資料，不會覆蓋或刪除你現有的記錄。備份是純文字檔，請放在只有你能讀到的地方。

## 隱私：全部都是選用的

- **沒有帳號、沒有購買、沒有行為分析。** Orbit 完全免費、MIT 授權。工作台在你的 Mac 上執行，不會連到網路。
- **登入時開啟**預設是關的。開啟後只註冊一個登入項目，把圖示放進選單列，不會多開視窗。
- **貓尾巴檔案架與截圖晾衣繩**預設是關的，在設定 → 模組開啟。
- **剪貼簿歷史、通知與提醒**都要你自己開啟；關閉剪貼簿時歷史也會清除。
- **更新**只在你要求時（或你開啟每日檢查後）才檢查，而且必須通過簽章驗證才安裝。
- **畫面擷取**使用 macOS 選取器：由你挑選視窗或內容，macOS 會請你確認這次選取。Orbit 不會自行錄製整個畫面。若不想用選取器，可以自己按 ⌘⇧3／⌘⇧4 截圖後匯入截圖頁，編修、OCR 與輸出功能都一樣。
- **快捷連結**只在你要求時才會在瀏覽器開啟。

## 語言

底部地球選單可選「系統／English／繁體中文」，切換立即生效並自動保存。預設跟隨 macOS 偏好語言；不支援的語言使用英文。主選單、工具提示與輔助標籤也會跟著切換。裝置名稱保持原樣。

## 顯示偏好

桌機可選 CPU／供電／隱藏外圈；筆電外圈使用電量。百分比文字、狀態色彩、主題、合併／傳統樣式、中央內容都能直接調整。

「圖示旁顯示百分比」與「中央百分比」互相獨立。中央需要有效讀值；充電中、桌機供電或隱藏外圈、機型／數值未知時，中央回到網路圖示，不假造0%或100%。傳統樣式沒有共用中央，因此中央選項會停用。

## 音訊與保持喚醒

音量／靜音以裝置支援能力為準；硬體自行控制音量的裝置不一定能從 App 調整。操作前會確認預設輸出未被其他程式改變。

選30／60／120分鐘，按「啟動」才開始；停止、到時或結束App即解除。它不會阻止闔上MacBook或手動睡眠。

## 周邊電量與充電

裝置有回報才顯示。充電閃電需要系統明確回報，並與裝置身分相符；不能從USB連線推論正在充電。沒有、衝突或型別不正確的資料一律保持未知。

## 請了解的限制

- 流量是介面收送資料，不是網速測試，也不是外網可用性檢查。
- 記憶體是active、wired與compressed的合計估值。
- 周邊讀值依賴macOS／裝置，並非每種耳機、手機或藍牙配件都能讀到。
- 不自動隱藏原生圖示；登入啟動與自動安裝都要你自己選擇。
- 未知資料顯示「—」或未知，不以假值補上。
- 截圖編修只處理你給它的內容，Orbit 不會修改原檔，輸出都是新檔案。

遇到問題可在GitHub回報。若要附 `--diagnose` 結果，請先移除不想公開的裝置、機型與介面資訊。

## 說明看起來是空的

⌘? 在 Orbit 於前景時可以開啟說明。說明隨 App 一起打包，沒有網路也能讀。

## 存不下來

Orbit 會保留無法讀取的原始檔並提供「備份並重設」。重設前先用該頁的「備份與匯入」匯出一份 JSON 副本。
