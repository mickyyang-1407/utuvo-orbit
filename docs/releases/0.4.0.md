# UTUVO Orbit 0.4.0

**Your Mac. In one small orbit.**

Orbit brings battery or CPU, network, and audio into a compact native macOS menu-bar glyph. Click for practical controls and live details, with appearance settings in the same panel.

## In this release

- One panel for controls and display preferences.
- Combined/classic glyphs and optional percentage displays.
- Audio output, volume, mute and timed keep-awake.
- Network activity, local IP, CPU/memory and readable peripheral batteries.
- Native Light/Dark/System appearance and Liquid Glass controls on supported macOS.
- MIT source, English/繁中 documentation and original app artwork.

## Downloads

- `UTUVO-Orbit-0.4.0-arm64.dmg` — drag to Applications.
- `UTUVO-Orbit-0.4.0-arm64.zip` — the same app, zipped.
- `UTUVO-Orbit-0.4.0-source.zip` — curated source and docs.
- `SHA256SUMS.txt` — hashes for the three downloads.

Apple Silicon. macOS 14+ source target; Liquid Glass requires macOS 26+. Tested on macOS 27. The initial download is **ad-hoc signed and not Apple-notarized**. Read the installation guide before first launch. App labels are currently Traditional Chinese.
